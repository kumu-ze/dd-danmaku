## 安装方式

任选其一：

### 1. 服务端嵌入（Docker / 裸机）

编辑 `/system/dashboard-ui/index.html`，在 `</body>` 前加入：

```html
<script src="https://cdn.jsdelivr.net/gh/kumu-ze/dd-danmaku@master/ede.js" defer></script>
```

### 2. 浏览器用户脚本（Tampermonkey 等）

复制 `ede.js` 内容新建脚本；或引用 RAW：

```html
// @require https://raw.githubusercontent.com/kumu-ze/dd-danmaku/master/ede.js
```

### 3. 客户端打包修改

解包 -> 修改 `dashboard-ui/index.html` -> 重新签名/打包。iOS 可用 AltStore / TrollStore，自行检索具体流程。

> 服务端与用户脚本方式可同时存在；用户脚本优先生效。

## 🎯 智能过滤系统说明

### 过滤等级说明

| 等级 | 每秒限制 | 质量阈值 | 垂直弹幕 | 说明 |
|------|---------|---------|---------|------|
| **0** | 无限制 | 无 | 无限制 | 关闭过滤，显示所有弹幕 |
| **1** | 5条 | ≥20分 | 4条/3秒 | 轻度过滤，过滤垃圾弹幕 |
| **2** | 3条 | ≥35分 | 3条/3秒 | 中度过滤，保留有意义弹幕 |
| **3** | 2条 | ≥45分 | 2条/3秒 | 重度过滤，仅保留优质弹幕 |
| **4** | 1条 | ≥55分 | 1条/3秒 | 极简模式，每秒仅1条高质量 |

### 弹幕质量评分机制

每条弹幕根据以下维度自动计算 0-100 质量分：

**加分项：**
- 适中长度（5-20字）：+15分
- 彩色弹幕：+5分
- 顶部/底部弹幕：+10分

**扣分项：**
- 单字弹幕：-30分
- 与最近弹幕完全相同：-40分
- 纯符号/表情：-35分
- 纯数字（如666666）：-25分
- 重复字符（如哈哈哈哈）：-20分
- 过长弹幕（>50字）：-20分

**工作原理：**
1. 为每条弹幕计算质量分
2. 每秒内按质量分降序排序
3. 优先保留高质量弹幕
4. 低于质量阈值的弹幕直接过滤

### 其他过滤选项

- **类型过滤**：顶部 / 底部 / 滚动 / 彩色 / emoji
- **来源过滤**：B站 / A站 / 巴哈 / 弹弹Play 等平台可单独屏蔽
- **关键词过滤**：大小写不敏感；支持正则表达式（格式：`/pattern/flags`）
- **用户屏蔽**：在弹幕列表中点击用户ID即可屏蔽，数据持久化存储

## 💾 缓存策略

| 类型     | Key 前缀              | TTL       | 说明                     |
| -------- | --------------------- | --------- | ------------------------ |
| 搜索     | `_search_cache_`      | 24h       | 仅缓存有效结果，空结果不缓存 |
| 弹幕     | `_danmaku_cache_`     | 1h        | LZString Base64 压缩存储  |
| 用户屏蔽 | `danmakuBlockedUsers` | 永久      | JSON 数组，含用户ID/来源 |

可在日志面板开关或清除缓存；用户屏蔽可在弹幕列表中管理。

## ❓ 常见问题 (FAQ)

**Q: 匹配不到弹幕？**  
A: 1) 查看日志是否显示"自动匹配失败" 2) 尝试手动搜索，使用"原标题"按钮切换 3) 新版本会自动尝试原始标题回退

**Q: 过滤等级改了没变化？**  
A: 1) 等级>0 才生效 2) 确认顶部过滤按钮图标已变化 3) 打开弹幕列表查看过滤数量

**Q: 热度曲线不显示？**  
A: 1) 检查外观设置中"热度轨迹"是否启用 2) 确认当前有弹幕数据

**Q: 如何屏蔽某个用户？**  
A: 打开弹幕列表，点击用户ID列或操作列的"屏蔽"按钮

**Q: 如何解除屏蔽？**  
A: 在弹幕列表中切换到"已屏蔽"标签页，点击"解除"按钮；或点击底部"清除屏蔽"清空所有

**Q: 等级4过滤后还是太多？**  
A: v2.3.0 已大幅加强，等级4每秒仅1条且质量分≥55。如仍需更严格过滤，可配合关键词过滤使用
