## 安装方式

任选其一：

### 1. 服务端嵌入（Docker / 裸机）

编辑 `/system/dashboard-ui/index.html`，在 `</body>` 前加入：

```html
<script src="https://cdn.jsdelivr.net/gh/kumu-ze/dd-danmaku@master/ede.js" defer></script>
```

### 2. 浏览器用户脚本（Tampermonkey 等）

复制 `ede.js` 内容新建脚本；或引用 RAW：

```html
// @require https://raw.githubusercontent.com/kumu-ze/dd-danmaku/master/ede.js
```

### 3. 客户端打包修改

解包 -> 修改 `dashboard-ui/index.html` -> 重新签名/打包。iOS 可用 AltStore / TrollStore，自行检索具体流程。

> 服务端与用户脚本方式可同时存在；用户脚本优先生效。

## 使用说明概览


| 入口     | 作用                                      |
| -------- | ----------------------------------------- |
| 弹幕开关 | 显示 / 隐藏弹幕（保留实例）               |
| 过滤等级 | 循环 0–4；0 关闭，>0 有并发/垂直密度限制 |
| 弹幕设置 | 快速外观：字体 / 不透明 / 速度 / 热度轨迹 |
| 弹幕中心 | 全部高级配置（外观 / 过滤 / 布局 / 高级） |
| 搜索     | 手动匹配：支持原标题按钮 & 自动回退逻辑   |
| 热度图   | 独立对话框；柱状 + 平滑线；点击跳转       |
| 日志     | 调试信息、CORS 测试、缓存管理、按钮排序   |

快捷键：

* Alt + H ：打开/关闭热度图

## 过滤系统说明

* 等级 (0–4)：限制时间片内弹幕量，并对高密度窗口动态调整。
* 类型过滤：顶部 / 底部 / 滚动 / 彩色 / emoji。
* 关键词：大小写不敏感；立即生效。
* Emoji 过滤：安全 fallback 正则，避免崩溃。

## 缓存策略


| 类型 | Key 前缀          | TTL       | 说明                     |
| ---- | ----------------- | --------- | ------------------------ |
| 搜索 | `_search_cache_`  | 24h       | 命中显示“使用缓存结果” |
| 弹幕 | `_danmaku_cache_` | 1h (压缩) | LZString Base64，自恢复  |

可在日志面板关闭或清除。

## 常见问题 (FAQ)

**Q: 匹配不到？** 先看日志是否显示“自动匹配失败”；尝试搜索界面切换“原标题”再搜。
**Q: 过滤等级改了没变化？** 等级>0 才生效；确认顶部过滤按钮图标变化；若仍旧 -> 日志查看原始/当前弹幕数。
**Q: 热度曲线不显示？** 可能被关闭：外观开关“热度轨迹”；或当前弹幕为空。

## 版本历史（节选）

### 2.0

> 2.0 = 聚合 + 自适应 + 可视化 + 体验提升。核心逻辑完整恢复并在此基础上扩展。

**重构 / 架构**

* 恢复并补全早期被截断的后半段逻辑（匹配、过滤、渲染协同）。
* 统一“弹幕中心”多标签：外观 / 过滤 / 布局 / 功能 / 高级，一处集中管理，移除分散旧弹窗。
* 快速外观面板独立（与主中心区隔），强调即时调节 + 低干扰。

**新增 / 功能提升**

* 弹幕速度独立可调（默认 200）+ 即时应用，无需重载实例。
* 中/原标题自动回退匹配：中文失败 → 原标题重试，提高命中率。
* 实时密度曲线（顶部覆盖）+ 热度图独立对话框（悬停预览 / 点击跳转时间）。
* 自适应密度守护：高峰期自动临时提升过滤等级并减速，条件满足后回落。
* 外部工具栏按钮自由勾选 + 拖拽排序 + 紧凑模式（行内密度提升）。
* 布局页内嵌轻量排序（无需进入日志再调）。
* 过滤等级外显按钮：循环 0–4 并动态图标反馈；支持一键暂存 / 恢复之前等级。

**过滤 / 安全**

* Emoji 过滤崩溃修复：使用宽字符安全正则 / 回退逻辑防止渲染中断。
* 关键词过滤立即生效（无需重拉），区分等级与关键词逻辑，避免交叉副作用。
* 类型过滤（顶部/底部/滚动/彩色/emoji）按钮化，状态可视。

**性能 / 缓存**

* 搜索缓存 24h / 弹幕缓存 1h（LZString Base64 压缩），支持日志面板一键清除或禁用。
* 重绘 / 重建路径合并：等级、速度、字体、透明度修改走差异更新。
* 过滤滑块 & 快速面板数值调节节流微优化（避免过度重排）。

**UI / 交互**

* 快速外观面板重制：渐变背景、实时数值徽章、区段色带（range painting）。
* 按钮图标状态统一更新（过滤等级 / 热度开关 / 信息显示）。
* 去除标题中冗余“层级”字样，精简视觉噪声。

**文档 / 元数据**

* Userscript 头部字段规范化（namespace / 版本规范 / 移除冗余作者注释）。
* README 全面改版（特性表 / FAQ / 缓存策略 / 变更日志体系化）。

**修复**

* showQuickAppearanceDialog 提前定义，修正引用顺序导致的 ReferenceError。
* 过滤按钮图标不同步问题（初始挂载与滑块/外按钮切换场景）。
* 排序偶发失效与多重定义函数风险。
